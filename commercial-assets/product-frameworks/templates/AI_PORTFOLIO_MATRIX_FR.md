# TIFINIA AI Value Studio — Portfolio Matrix

## Axes

- Axe horizontal : faisabilité / readiness
- Axe vertical : valeur business
- Taille de la bulle : effort ou investissement estimé
- Couleur : niveau de risque

## Catégories

### Quick Wins
Valeur forte, faisabilité élevée, risque maîtrisable.

### Strategic Bets
Valeur très forte, mais dépendances ou transformation importantes.

### Foundations
Travaux data, intégration, sécurité ou gouvernance nécessaires avant les use cases visibles.

### Defer / Reject
Valeur trop faible, risque disproportionné ou problème mal défini.

## Règle de décision

Aucun use case ne passe en pilote sans :

- un sponsor métier identifié ;
- une métrique de succès ;
- une source de données accessible ;
- un niveau de risque accepté ;
- une hypothèse de valeur testable.
